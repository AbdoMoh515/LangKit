# Session 001 — 2026-09-12 — phase-01-foundations

## What was taught

6 new greeting/courtesy items (target load 5–10, adapted to 30-min budget):

- terima kasih (thank you) — sense: thank-you
- selamat pagi (good morning) — sense: greeting-time
- maaf (sorry) — sense: apology
- permisi (excuse me) — sense: politeness-attention
- ya / tidak (yes / no)
- apa kabar? (how are you?) — sense: greeting-inquiry

Each item followed the loop: introduce → meaning/usage → pronunciation
guidance (Google Translate listen link provided) → one example sentence with
translation → recognition → active recall.

## Exercise results

| Exercise | Type | Result |
|---|---|---|
| "Terima ___ banyak." (context: thanks) | recognition | correct |
| meaning → word: "thank you" | active recall | correct |
| meaning → word: "good morning" | active recall | **error** — learner recalled "selamat" only; explained that selamat is the generic root, pagi specifies morning. Retried: correct. |
| word → meaning: "maaf" | active recall | correct |

## Remediation

- "selamat pagi" error was a partial-recall error (root retrieved, specifier
  missing). Explained root+specifier pattern; item deferred for spaced
  reassessment in session 2 rather than drilled repeatedly.
